# ARVELIS AI — Brand Assets

## Утверждённая композиция

- геометрическая золотая буква `A`;
- круговая орбита;
- правая часть орбиты переходит в точечную дугу;
- под знаком `ARVELIS`;
- ниже `AI` между тонкими горизонтальными линиями;
- слоган `INTELLIGENCE. PRECISION. RESULTS.`

## Текущие чистые технические ассеты

- `public/brand/logo-mark.svg` — основной чистый SVG знака для интерфейсного preview;
- `public/brand/logo-mark-small.svg` — тот же утверждённый знак с идентичной геометрией, экспортный SVG 64×64 для малых интерфейсных размеров;
- `public/brand/favicon.svg` — отдельный favicon SVG на базе **той же геометрии**, без изменения формы знака.

Эти файлы не используют вырезанный постер или растровый скриншот.

## Важно о master-lockup

Полный lockup внутри текущего React preview собирается из SVG-знака и текстовой типографики интерфейса. Это **не считается финальным master-brand asset**.

Финальный `logo-full*.svg` нельзя выдавать за готовый, пока не утверждена точная векторная типографика/outline wordmark. Создавать случайный системный шрифт внутри master-SVG запрещено.

## Правила

- не использовать вырезанный постер или размытый скриншот;
- не менять форму знака без отдельного подтверждения;
- малый знак должен оставаться читаемым;
- точечная дуга не должна превращаться в шум;
- сильное glow допускается только в презентационных материалах;
- интерфейсные версии должны сохранять высокую читаемость;
- финальный master-lockup должен быть самодостаточным и не зависеть от случайного системного шрифта.
