# ARVELIS AI — зафиксированные решения

## 2026-08-20 — Brand

- Название: `ARVELIS AI`.
- Слоган: `INTELLIGENCE. PRECISION. RESULTS.`
- Базовое визуальное направление: профессиональное, премиальное, графитово-золотое.
- Логотип: геометрическая золотая `A` внутри круговой орбиты с точечной правой дугой.
- Полная композиция: знак, `ARVELIS`, ниже `AI` между тонкими линиями, затем слоган.
- Форма логотипа, композиция, название и слоган не меняются без отдельного подтверждения.

## 2026-08-20 — Product

- Официальное позиционирование: `ARVELIS AI — профессиональный универсальный ИИ-ассистент для работы, учёбы и решения сложных повседневных задач.`
- Продукт создаётся для широкой аудитории.
- Первый AI MVP не должен автоматически пытаться одинаково глубоко закрыть все категории; главная проблема первого AI-релиза ещё не выбрана.

## 2026-08-20 — UX character

- Продукт не должен ощущаться холодным или чрезмерно строгим.
- Пользовательский тон: `живой + дружелюбный + профессиональный`.
- Премиальное графитово-золотое визуальное направление сохраняется.
- Основной CTA входа: `Открыть ARVELIS AI`, а не `Открыть рабочее пространство`.
- Стартовый экран внутри продукта называется `ARVELIS AI`.
- При доступном имени интерфейс приветствует пользователя по имени.
- Основные формулировки должны приглашать к работе (`С чего начнём?`), а не звучать как канцелярская команда.

## 2026-08-20 — Smart Entry

- Loading-screen ARVELIS AI должен отображать утверждённый бренд и сдержанную анимацию.
- Загрузка не имитируется таймером.
- Процент показывается только для реально завершённых задач подготовки.
- Критические screen chunks и локальное состояние готовятся до входа.
- Второстепенные модули прогреваются после первого render в idle/background режиме.
- Lazy fallback без измеримого прогресса используется как indeterminate state без фиктивного процента.
- Тёплый cache имеет право проходить loading-screen очень быстро; искусственно удерживать заставку запрещено.

## 2026-08-20 — Current scope

- Сначала product foundation, бренд-ассеты и рабочий интерфейс.
- Реальный AI подключается только после закрытия обязательных gate из `docs/06_MVP_GATES.md`.
- Внешние интеграции не входят в текущий этап.
- Preview/mock элементы всегда маркируются как `PREVIEW/MOCK` и не выдаются за AI/backend.

## 2026-08-20 — Preview technical stack

Для runnable frontend-preview зафиксирован текущий стек:

- React 19.2.8;
- React DOM 19.2.8;
- TypeScript 6.0.3;
- Vite 8.2.1;
- Node.js 22.12+;
- Replit runtime без Replit Agent;
- локальное состояние через browser `localStorage`.

Это **не утверждает production technical stack**, backend, auth, database или AI provider.

## 2026-08-20 — Git workflow

- Источник истины: GitHub.
- `main` — стабильная ветка.
- Разработка: отдельные рабочие ветки.
- Текущий post-merge/Smart Entry candidate: `fix/post-merge-mobile-qa-v1`.
- Merge в `main`, force push, удаление веток и production deploy — только после отдельного подтверждения.
- Replit Agent не используется для обычной разработки; обновление тестового Replit идёт через GitHub Pull.

## 2026-08-20 — Preview QA

- `main` после PR №6 фактически запускался в Replit на iPhone.
- Welcome, стартовый экран, Chat, History и Profile были повторно проверены по реальному запуску и скриншотам.
- Реальный iPhone-тест выявил keyboard/composer gap и touch-hover артефакт; исправления находятся в текущем Draft candidate.
- Smart Entry/lazy-loading candidate ещё не проверен через Replit `Pull → Run` и поэтому не считается runtime-подтверждённым.

## Не утверждено для production

- одна главная проблема первого AI MVP;
- финальные границы AI MVP;
- AI-провайдер и модель;
- production technical stack;
- production database/data model;
- настоящая авторизация, роли и уровни доступа;
- финальные требования по персональным данным;
- биллинг и тарифы;
- production-хостинг;
- критерии готовности AI-релиза;
- дата публичного запуска.
