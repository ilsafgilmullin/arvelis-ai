# ARVELIS AI — Chat Experience QA

Основание: реальный iPhone preview после merge PR №8.

## Наблюдения по фактическим скриншотам

Подтверждено:

- Smart Entry работает и персональное приветствие отображается;
- Home стал живее и использует имя пользователя;
- Chat функционально работает и локальные сообщения сохраняются;
- после нормализации на диалог остаётся одно preview-status сообщение;
- текущая визуальная модель Chat всё ещё выглядит слишком технической: квадратные пользовательские карточки, служебная подпись под composer и большое количество жёстких рамок;
- на Smart Entry при scrollable mobile layout виден системный scrollbar справа.

## Цель candidate

Сделать Chat похожим по удобству на современный conversational AI-интерфейс, но не копировать чужой бренд или визуальную систему.

ARVELIS AI сохраняет:

- графитово-золотой бренд;
- собственную геометрию логотипа;
- маркировку PREVIEW;
- прозрачное указание, что AI/backend ещё не подключены;
- mobile-first навигацию продукта.

## Что меняется

### Conversation flow

- пользовательское сообщение — компактная правая bubble без тяжёлой квадратной карточки;
- assistant/mock сообщение — спокойная полноширинная зона с ARVELIS AI identity;
- системный preview-status — компактное notice-состояние, а не крупный системный message block;
- время сообщения визуально вторично;
- размер основного текста на iPhone повышен для нормальной читаемости.

### Composer

- composer получает округлённую floating/capsule форму;
- кнопки `+` и отправки становятся круглыми touch-targets;
- служебный helper скрывается на mobile;
- существующий `visualViewport` keyboard hardening сохраняется;
- mobile navigation скрывается при фокусе в textarea, как и в текущем runtime.

### Smart Entry

- загрузочный экран остаётся scrollable на коротких устройствах;
- визуальный системный scrollbar скрывается, не отключая саму прокрутку.

### Naming

- desktop navigation больше не использует старое `Рабочее пространство`;
- основной раздел называется `ARVELIS AI`.

## Проверка после будущего merge

1. Replit → Git → Pull → Run.
2. Smart Entry: проверить отсутствие видимой scrollbar-полосы справа.
3. Home: убедиться, что персональное приветствие и нижняя навигация не изменились функционально.
4. Открыть существующий диалог с несколькими сообщениями.
5. Пользовательские сообщения должны выглядеть как компактные правые bubbles без тяжёлой рамки-карточки.
6. Preview-status должен отображаться как одно компактное notice.
7. Если в demo-истории есть assistant/mock — проверить ARVELIS AI label и отсутствие визуальной путаницы с пользовательским сообщением.
8. Создать новый диалог: empty-state должен быть дружелюбным и честно сообщать про preview.
9. Открыть iPhone keyboard: composer должен оставаться в доступной области, mobile nav должна скрыться.
10. Ввести многострочный текст: textarea должна расти до установленного max-height.
11. Отправить короткое и длинное сообщение: длинный текст не должен давать horizontal overflow.
12. Закрыть keyboard: mobile nav и обычная sticky-позиция composer должны восстановиться.
13. Проверить 320–360 px и landscape при возможности.
14. Desktop: sidebar должен показывать `ARVELIS AI`, а не `Рабочее пространство`.

## Вне scope

- реальные AI-ответы;
- streaming tokens;
- attachment upload;
- voice input;
- web search;
- citations;
- backend/auth;
- изменение утверждённого логотипа или базовой цветовой системы.

Эти функции не считаются реализованными или утверждёнными этим candidate.
