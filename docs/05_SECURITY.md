# ARVELIS AI — безопасность

- AI-ключи никогда не передаются клиенту.
- Все AI-запросы в будущем проходят через доверенный серверный gateway.
- Пользовательские данные минимизируются.
- Чувствительные данные не попадают в логи без необходимости.
- Авторизация и роли проверяются сервером.
- Для файлов обязательны проверки содержимого, размера, имени и допустимого типа.
- Для AI обязательна защита от prompt injection, утечки системных инструкций и неконтролируемых инструментов.
- Любое внешнее рискованное действие требует политики разрешений и подтверждения пользователя.
- Ограничиваются частота, стоимость и длительность запросов.
- Предусматриваются удаление аккаунта, экспорт/удаление данных, backup и recovery.
- До публичного запуска отдельно проверяются требования к персональным данным и доступности инфраструктуры в России.
- Продукт нельзя называть production-ready без фактического аудита.
