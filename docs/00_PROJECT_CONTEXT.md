# ARVELIS AI — контекст проекта

## Статус

ARVELIS AI создаётся с нуля как отдельный публичный продукт.

## Утверждено

- Название: `ARVELIS AI`.
- Позиционирование: профессиональный универсальный ИИ-ассистент для работы, учёбы и решения сложных повседневных задач.
- Слоган: `INTELLIGENCE. PRECISION. RESULTS.`
- Стиль: строгий, профессиональный, премиальный, графитово-золотой.
- Основной знак: геометрическая золотая буква `A` внутри круговой орбиты.
- Правая часть орбиты переходит в точечную дугу.
- Под знаком: `ARVELIS`, ниже `AI` между тонкими линиями.
- Интерфейс: mobile-first, с отдельной desktop-адаптацией.
- Внешние интеграции не входят в текущий этап.

## Не утверждено

- точная главная проблема первого AI MVP;
- окончательный набор функций MVP;
- AI-провайдер;
- технический стек;
- модель данных;
- авторизация и роли;
- биллинг и тарифы;
- production-хостинг;
- дата запуска.

Источник истины для кода: текущий GitHub-репозиторий и активная ветка.
