# ARVELIS AI — архитектура

## Принципы

- mobile-first frontend;
- UI, доменная логика, данные и AI-интеграции разделяются;
- AI-слой должен быть провайдер-независимым;
- серверная авторизация и контроль доступа;
- отдельный аудит действий и AI-операций;
- demo/mock отделяются от production;
- секреты только в защищённом окружении.

## Текущий frontend-прототип

Для первого интерфейсного прототипа используется минимальный стек:

- React 19.2.x;
- TypeScript 6.x;
- Vite 8.1;
- Node.js 22.12+; рекомендуемая LTS-линия для CI/production-подготовки — Node 24;
- без router-зависимости;
- без UI framework;
- без backend;
- без реального AI;
- без реальной авторизации;
- без серверного хранения.

Это техническое решение для первого frontend-этапа, а не окончательная production-архитектура.

## Будущий AI gateway

Серверный слой должен:
- выбирать провайдера и модель;
- валидировать вход;
- применять системные политики;
- ограничивать стоимость и частоту;
- минимизировать чувствительные данные;
- журналировать технические метаданные;
- поддерживать таймаут, отмену и повтор;
- не раскрывать API-ключи клиенту.
